The choir repo on github:  https://github.com/crpc-choir/choir-songbook

The choir can now open it on any phone at https://crpc-choir.github.io/choir-songbook/.

Your routine from now on:

Edit data/catalogue.csv, then run source("R/build_songs.R") in the Console.

Type lyrics into the files in songs/.

In the Terminal, run:
quarto preview
git pull
quarto render
git add .
git commit -m "add Offline app "
git push
